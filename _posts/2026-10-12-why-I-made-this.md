So, why did I make this?   
Basically, I wanted a space for myself to somewhat sort through my thoughts and rather than a diary, this'll just solely for projects I'm working on or stuff I'm doing in between projects.    

Currently, I'm rewriting my bot I made a while ago for Twitch and Osu. UsagiBot.    
The main goal for the bot is to make sure it works with both lazer and stable. 
I had an issue recently where something broke and I decided that I probably should go and fix it finally. 
The bot itself was so bloated with shit and stuff I never actually used, I thought I probably should finally rewrite it. 
With the help of Claude, I have been slowly rewriting the entire bot from scratch. Keeping in some stuff that already worked and making other things that could be better... better.
There's a few things I really want in this bot that wasn't in the previous one. For example, before, I would have a custom tag for each element if someone wanted to customize the default message scripts. 
It was placed in two different functions and I would have to update each whenever I added a new tag. This time, I just want one class that handles it all.
I'm changing up the way the data is stored so that I can have comments in the config file and I also want it to work on Mac, Linux, and Windows.
I thought about finally making a GUI, but I really dislike UI design, and I'm not good at it at all.
We'll see how it goes.
